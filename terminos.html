INFORMACIÓN DEL PROYECTO

Términos y condiciones de uso

Última actualización: 26 de julio de 2026

Aviso importante

Ventech es un proyecto académico y demostrativo. No constituye actualmente un establecimiento de comercio, no realiza ventas reales, no recibe dinero y no procesa información bancaria.

1. Identificación y finalidad

Ventech simula una tienda virtual de productos tecnológicos con fines educativos relacionados con análisis, diseño y desarrollo de software. Sus funciones de catálogo, usuarios, inventario, carrito, pedidos, facturas y pagos se presentan únicamente para demostrar un flujo de comercio electrónico.

2. Aceptación

Al utilizar el sitio, la persona declara haber leído y comprendido estos términos. Si no está de acuerdo, debe abstenerse de registrarse o usar las funciones demostrativas.

3. Registro y datos de prueba

Los datos ingresados se utilizan exclusivamente para probar las funciones del proyecto. Se recomienda no introducir contraseñas reutilizadas, números de tarjetas, información financiera, documentos reales ni datos sensibles.

4. Catálogo y precios

Los productos, imágenes, existencias, descuentos, impuestos, garantías y precios mostrados pueden ser ficticios o referenciales. No constituyen una oferta comercial vinculante ni generan obligación de entregar productos.

5. Carrito y pedidos

Agregar artículos al carrito o confirmar un pedido crea únicamente un registro académico dentro del sistema. No se celebra un contrato de compraventa y no se despacha mercancía.

6. Pagos simulados

Las opciones denominadas PSE o tarjeta son simulaciones de interfaz. Ventech no solicita números de tarjeta, claves, códigos de seguridad ni credenciales bancarias. Ningún botón del proyecto debe interpretarse como autorización para realizar un débito o transferencia real.

7. Facturas y comprobantes

Las facturas, referencias, estados de pago y comprobantes generados carecen de validez fiscal o comercial. Se crean solamente para demostrar las capacidades del sistema.

8. Imágenes y contenido

Las imágenes de productos y variantes de color se usan únicamente dentro del entorno académico. Quien las cargue debe contar con autorización y evitar contenido ilegal, ofensivo o protegido sin permiso.

9. Disponibilidad y cambios

El proyecto puede cambiar, suspenderse, reiniciarse o eliminar datos sin previo aviso. No se garantiza disponibilidad continua, ausencia de errores ni conservación permanente de la información.

10. Seguridad

No deben utilizarse datos financieros ni credenciales reales. Si el sitio se transforma posteriormente en una tienda comercial, deberá implementarse una pasarela certificada, protección de datos y documentación legal independiente antes de recibir dinero.

11. Responsabilidad

Ventech se ofrece con fines de aprendizaje. Sus autores no asumen obligaciones derivadas de compras, entregas, garantías, devoluciones o pagos, porque estas operaciones no se realizan realmente.

12. Contacto académico

Las observaciones deben dirigirse al responsable académico o instructor asociado al proyecto. Este canal no corresponde a servicio al cliente de una empresa comercial.
